# QuayeWorks Classes

A simple site for learners to sign in, pick a class, and practice questions in one place.

## Courses

- **CLS** - the original Combat Lifesaver modules and question bank.
- **CompTIA Security+ SY0-701** - five certification-guide domains containing Chapters 1-29, randomized 25-question chapter quizzes, randomized domain tests, and a 90-question timed final.

Each course has separate local progress and exam saves. The Security+ bank contains 1,341 original, objective-aligned practice questions informed by the official SY0-701 objectives and ExamCompass topic coverage; it does not reproduce ExamCompass questions or certification exam dumps. The CLS course and question bank remain separate from Security+.
