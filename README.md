# QuayeWorks Classes

A simple site for learners to sign in, pick a class, and practice questions in one place.

## Courses

- **CLS** - the original Combat Lifesaver modules and question bank.
- **CompTIA Security+ SY0-701** - five certification-guide domains containing Chapters 1-29, individual chapter quizzes, randomized domain tests, and a 90-question timed final.

Each course has separate local progress and exam saves. Security+ practice content is original and objective-aligned; it does not contain real certification exam questions or dumps. The CLS course and question bank remain separate from Security+.
