# QuayeWorks Class

A simple site for Army Soldiers to sign in, test their knowlede in military courses and civilian certifications.
## Courses

- **CLS** - the original Combat Lifesaver modules and question bank.
- **CompTIA Security+ SY0-701** - five certification-guide domains containing Chapters 1-29, randomized 25-question chapter quizzes, randomized domain tests, and a 90-question timed final.
- **IRON LINK 01** - a generic Packet Tracer network build with a cable and IP plan, nine evidence-backed milestones, ten knowledge questions, six troubleshooting drills, and local progress export/import.

The Security+ bank contains 1,300+ original, objective-aligned practice questions informed by the official SY0-701 objectives and ExamCompass topic coverage; 

[Open QuayeWorks Classes](https://quayeworks.github.io/Class/)

### IRON LINK 01

Log in with the site's demo credentials, open IRON LINK 01 in the catalog, and build the network in Cisco Packet Tracer. The tracker is self verified: it cannot open or grade a `.pkt` file. Checklist and evidence notes are stored in the current browser's local storage; use **Record → Export progress JSON** to transfer or back them up. The exercise is unclassified and uses a generic topology, not an operational Army configuration. Do not record real credentials or sensitive infrastructure details.
