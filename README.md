# QuayeWorks Class

A simple site for Army Soldiers to sign in, test their knowlede in military courses and civilian certifications.
## Courses

- **CLS** - the original Combat Lifesaver modules and question bank.
- **CompTIA Security+ SY0-701** - five certification-guide domains containing Chapters 1-29, randomized 25-question chapter quizzes, randomized domain tests, and a 90-question timed final.

Each course has separate local progress and exam saves. The Security+ bank contains 1,300+ original, objective-aligned practice questions informed by the official SY0-701 objectives and ExamCompass topic coverage;
